# 🌐 Indian Language Translator Tool

Welcome to the **Indian Language Translator Tool**! This is a simple, fast, and responsive web-based translation application built to help users seamlessly translate text across multiple Indian regional languages and popular global languages.

## ✨ Features
- **Accurate Translation:** Powered by the Google Translate API for fast and highly accurate results.
- **Multiple Languages Supported:** Includes English, Hindi (हिंदी), Urdu (اردو), Bengali, Marathi, Telugu, Tamil, Gujarati, Kannada, Malayalam, Punjabi, Sanskrit (संस्कृतम्), Spanish, French, and Arabic.
- **Text-to-Speech (Audio):** Built-in voice feature to listen to both the input text and the translated output.
- **One-Click Copy:** Easily copy the translated text to your clipboard with a single click.
- **Live Clock:** Displays the current time and date in real-time.
- **Responsive Design:** A clean, mobile-friendly UI that works perfectly on smartphones, tablets, and desktop computers.

## 🛠️ Technologies Used
- **HTML5:** For the structure and layout.
- **CSS3:** For styling, modern UI design, and responsive media queries.
- **JavaScript (Vanilla JS):** For logic handling, fetching API data, live clock updates, and Web Speech API (Text-to-Speech).
- **API Used:** Google Translate API.

## 🚀 How to Use
1. You can visit the live website here: *(Add your Netlify or GitHub Pages link here)*
2. Select your **Source Language** from the first dropdown.
3. Select your **Target Language** from the second dropdown.
4. Type or paste the text you want to translate.
5. Click on **"Translate Text"** to get the output.
6. Use the 🔊 icon to listen to the pronunciation or the 📋 icon to copy the text.
